Fine-tuning large language models (LLMs) can be computationally expensive, and its outcomes depend heavily on dataset quality and training configurations. This project introduces **TuneAhead**, a lightweight framework for predicting fine-tuning performance before committing to full training.

TuneAhead combines static dataset characteristics with dynamic features collected through short probe runs to estimate fine-tuning outcomes. It also provides interpretable insights into the factors driving these predictions. Evaluated across more than 1,300 fine-tuning runs, TuneAhead demonstrates accurate performance prediction, helping researchers identify promising configurations and reduce unnecessary training costs.
